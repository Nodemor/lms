# Site photos

Put these three photos in this folder (same file names). The site picks them up automatically;
if a file is missing, a plain brand background is shown instead, so nothing ever looks broken.

| File | Where it appears | Best photo | Size |
|---|---|---|---|
| `hero-teacher.jpg` | Home page, large photo | A teacher teaching (whiteboard, classroom or online) | 1200 × 1500 px (portrait) |
| `hero-student.jpg` | Home page, small photo | A student studying with a phone or laptop | 800 × 800 px (square) |
| `auth.jpg` | Sign in / Sign up, left side | Students in a class or studying together | 1400 × 1800 px (portrait) |

Tips
- Use real photos of your own teachers and students (with their permission). That builds the most trust.
- Free photos you may use commercially: Unsplash (unsplash.com/license) and Pexels (pexels.com/license).
  Search for "Sri Lankan student", "teacher classroom", "student studying laptop".
- Keep each file under ~400 KB (compress at squoosh.app) so pages load fast on mobile data.
